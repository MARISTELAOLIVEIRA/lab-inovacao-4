# 🛠️ Laboratório de Inovação IV: do problema ao protótipo

Site da disciplina **Laboratório de Inovação IV** (ADS, 4º semestre, noturno) da Faculdade de Tecnologia e
Inovação Senac DF, com a Profa. Maristela (Stela).

**No ar:** https://maristelaoliveira.github.io/lab-inovacao-4/

## O projeto do semestre

Em grupos, a turma escolhe um desafio real do Sistema Fecomércio, entende o problema com Design Thinking,
organiza o trabalho em sprints, constrói um protótipo funcional (de preferência com IA), testa com usuários,
apresenta na **Feira de Tecnologia** e entrega a documentação no GitHub.

| Pasta | O que é |
|---|---|
| [`index.html`](index.html) | Página da disciplina: ementa, objetivos, unidades, aulas, avaliação e bibliografia |
| [`aulas/`](aulas/) | Uma página por aula, com conceitos, estudo de caso, atividade e checklist |
| `assets/` | Visual comum aos sites da Stela (placa de circuito, tema claro e escuro, chuva de 0 e 1) |

## Tecnologia

HTML, CSS e JavaScript puros, sem framework e sem etapa de build. Acessível: tema claro e escuro, aumento
de texto e botão para pausar as animações em todas as páginas.

Feito com ♥ e sucata eletrônica.
